## Andrew Fila

Software engineer in Denver. Mostly C++ and TypeScript, some C and Java.
Lately I've been working on smart lights, from the network protocol down to
the hardware. More at [fila.nexus](https://fila.nexus).

**[clifx](https://github.com/AndrewFila/clifx)**: the LIFX LAN protocol in
C++20. It packs and unpacks the packets the bulbs speak, and every message type
has round-trip tests.

**[clifx-hw-esp32](https://github.com/AndrewFila/clifx-hw-esp32)**: the start of a
physical controller for the lights, an ESP32 with a dial and a couple of
knobs. Still a prototype.

**[yomi](https://github.com/AndrewFila/yomi)**: the color scheme I use in the
terminal and in Neovim.

**[dotfiles](https://github.com/AndrewFila/dotfiles)**: everything else about
how I work: Neovim, tmux and zsh on WSL.
